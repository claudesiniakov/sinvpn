# SinVpn

Приложение для строки меню macOS: включает и выключает VPN-подключения, настроенные в «Системных настройках», и показывает по ним время работы и трафик.

ТЗ: https://claude.ai/artifact/X8AQWokdMRPTZBe7EbM5eF

## Что умеет

- Значок «VPN в рамке» в строке меню: контур — выключено, мигает — подключение, залит — подключено.
- Панель из двух блоков:
  - **VPN** — переключатель на каждое подключение из раздела VPN «Системных настроек»;
  - **Статистика** — время, принятый и отправленный трафик за сессию, сегодня и 30 дней.
- Автозапуск при входе в систему.
- Обновление из GitHub Releases по кнопке «Обновить» (проверка — при запуске и раз в сутки).

Приложение не создаёт своих VPN, не хранит пароли и ничего не отправляет в сеть, кроме запроса к GitHub за обновлениями. Статистика лежит в `~/Library/Application Support/SinVpn/stats.json`.

## Требования

- Mac на Apple Silicon, macOS 14 или новее.

## Установка

1. Скачайте `SinVpn.zip` со страницы [релизов](https://github.com/claudesiniakov/sinvpn/releases) и распакуйте.
2. Перенесите `SinVpn.app` в «Программы».
3. Сборка подписана ad-hoc (без Developer ID), поэтому при первом запуске откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

## Как устроено

| Часть | Реализация |
| --- | --- |
| Значок и панель | SwiftUI `MenuBarExtra`, `LSUIElement` |
| Список и переключение VPN | `scutil --nc list / start / stop` |
| Отслеживание изменений | уведомления `SCDynamicStore` + редкий опрос |
| Трафик | 64-битные счётчики интерфейсов, `sysctl NET_RT_IFLIST2` |
| Автозапуск | агент запуска в `~/Library/LaunchAgents` (не зависит от подписи приложения) |
| Обновление | GitHub Releases: архив + SHA-256, проверка подписи, замена бандла |

- `Sources/SinVpnCore` — логика без интерфейса, покрыта тестами.
- `Sources/SinVpn` — приложение.

## Сборка

На сервере разработки Swift нет: сборка и тесты идут в GitHub Actions (`.github/workflows/ci.yml`). Локально на Mac:

```sh
swift test
./scripts/build-app.sh   # build/SinVpn.app и build/SinVpn.zip
```

Релиз публикуется при пуше тега `vX.Y.Z`; текст аннотации тега становится описанием релиза.
